# LARAPÊ — Homepage V4

Inclui a homepage, fluxo de solicitação, seção “Trabalhe com a LARAPÊ” e um primeiro painel administrativo.

## Painel administrativo
Abra `admin.html` para visualizar as candidaturas feitas pelo formulário da homepage.

Os dados de candidatura são salvos no `localStorage` do navegador apenas para demonstração. O currículo não é enviado a um servidor nesta versão; apenas o nome do arquivo é registrado.

Para produção, será necessário conectar um backend/banco de dados e armazenamento seguro de documentos.
